# 🍽️ RestMenu

**RestMenu** è il tuo archivio digitale dei menu dei ristoranti: fotografi il menu di un locale, lo organizzi e lo ritrovi quando vuoi — cercando per ristorante, città o piatto.

**🔗 Demo live:** [restmenu.onrender.com](https://restmenu.onrender.com/)

![Schermata di RestMenu](./screenshot.png)

## Funzionalità

- **Scansiona un menu** — fotografa il menu di un ristorante e trasformalo in pochi istanti in una voce del tuo archivio.
- **Cerca ristorante, città o piatto** — ritrova rapidamente ciò che hai salvato in precedenza.
- **I tuoi ristoranti** — tutti i locali visitati organizzati in un unico posto, sempre a portata di mano.
- **Interfaccia mobile-first** — pensata per essere usata dal telefono, con barra di navigazione dedicata (Home, Scansiona, Ristoranti).
- **Installabile come app** — è una PWA, quindi può essere aggiunta alla schermata Home del telefono.

## Come è fatta

Applicazione web realizzata in **React** (con build **Vite**), distribuita come **PWA** installabile grazie a un Web App Manifest. Il deploy è ospitato su **Render**.

## Provarla

Basta aprire la demo live, non serve installare nulla: [restmenu.onrender.com](https://restmenu.onrender.com/)

Per installarla sul telefono:
- **Android (Chrome):** apri il link, tocca il menu (⋮) e scegli "Aggiungi a schermata Home" / "Installa app".
- **iPhone (Safari):** apri il link, tocca l'icona di condivisione, poi "Aggiungi alla schermata Home".
